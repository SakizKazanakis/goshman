# GOSHMAN v3.0 — verified five-view visual QA (2026-10-25)

## Baseline evidence

- Real Blender 5.2.3 generated a procedural 172-mesh GLB/BLEND baseline, plus five orthographic RGB+alpha PNG views.
- CI: [Linux Blender and Windows packaged EXE](https://github.com/SakizKazanakis/goshman/actions/runs/40185464230) passed after testing the five-view renderer and actual RGB image content.
- Earlier build output was materially defective: all 256x256 base-color, normal, roughness and metallic PNGs loaded as black RGB with alpha 255 despite successful structural checks.
- Fix in `goshman/pbr_blender.py`: write deterministic RGBA PNG bytes from the actual generated arrays and re-open the files as Blender images before packing/export. CI now checks real colour channels and rendered output luminance.
- Verified corrected mean RGB at 256px: scales base (73.8,113.6,35.7), belly base (181.2,153.7,85.6), scales normal (127.5,127.5,246.3), scales roughness (132.3,132.3,132.3).
- Source input SHA-256 checks passed for all 12 private reference sheets. No original sheets or local QA comparison artwork were uploaded to GitHub.
- The five-view procedural baseline was compared against real source views in the authorized isolated workspace. The mesh **does not visually resemble the required crocodile**: anatomy, head, jaw, hands, clothing and tail do not match. `PASS_RENDER_TECHNICAL` intentionally **does not mean** `PASS_VISUAL_ACCEPTANCE`.
